
# Day 11 - Data Cleaning and Visualization

## Project Overview
This project uses Pandas, Matplotlib, and Seaborn to clean and analyze student performance data.

## Data Cleaning
- Checked missing values in the dataset.
- Removed duplicate records.
- Checked and converted subject marks to numeric values.
- Created the Average_Score column using Python, Mathematics, Statistics, and Machine Learning marks.
- Added Performance categories: Excellent, Good, Average, and Needs Improvement.
- Sorted students by average score.
- Saved the cleaned data as cleaned_student_performance.csv.

## Visualizations
The project creates the following charts:
- Bar chart of each student's average score.
- Histogram showing the distribution of average scores.
- Scatter plot comparing Python and Machine Learning marks.
- Pie chart showing performance categories.
- Box plot showing the spread of subject marks.
- Subject average chart.
- Top five students chart.

These charts help identify score patterns, compare subjects, and understand student performance.

## Dashboard Analysis
The dashboard reports:
- Total number of students.
- Average marks for each subject.
- Top five performing students.
- Students who need improvement.
- Subject with the highest class average.
- Key findings from the dataset.

## Dataset
The original dataset contains 20 student records and is stored in the Day6 folder.
