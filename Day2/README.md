## Student Record Management System

I also built a console-based Student Record Management System using Python lists and dictionaries.

### Features

- Add Student
- View All Students
- Search Student by Roll Number
- Update Student Information
- Delete Student
- Calculate Average Marks
- Assign Grades
- Display Total Number of Students
- Menu Driven Interface

## Data Stored

Each student record contains:

- Name
- Roll Number
- Age
- Course
- Subjects
- Marks
- Average
- Grade

## Challenges Faced

One challenge was understanding how to organize student information using lists and dictionaries.

Another challenge was implementing the menu-driven system and handling different operations such as searching, updating, and deleting student records.

## Solutions Implemented

I used:

- Lists to store multiple student records
- Dictionaries to store individual student information
- Loops to search and process student records
- Functions to organize different operations
- Conditional statements to calculate grades
- Dictionary methods to manage student data
