Day-6: NumPy, Pandas and Student Performance Analysis

What I Learned

NumPy

I learned how to work with NumPy arrays. I practiced creating 1D and 2D arrays, performing arithmetic operations, finding maximum, minimum, mean and sum, reshaping arrays, and using indexing and slicing.

Pandas

I learned how to work with datasets using Pandas. I practiced loading CSV files, displaying the first and last rows, checking dataset information, finding missing values, filtering data, and calculating summary statistics.

Student Performance Analysis

For the mini project, I used a student performance dataset containing student information, programs, subject marks, and attendance.

I used Pandas to load and analyze the dataset. I calculated the average marks for Python, Mathematics, Statistics, and Machine Learning. I also calculated each student's average marks and identified the top 5 performing students.

I found students scoring below the overall class average and calculated the total number of students. Finally, I saved the processed dataset as a new CSV file.

Key Insights

* The dataset contains 5 students.
* Students have marks for four subjects: Python, Mathematics, Statistics, and Machine Learning.
* Ahmed Raza is one of the highest-performing students based on average marks.
* The processed dataset contains an additional `Average_Marks` column.
* The analyzed data was saved into `processed_student_performance.csv`.

Challenges Faced

The main challenge was understanding the correct file path while loading the CSV files. I also learned how to use Pandas functions such as `head()`, `tail()`, `info()`, `isnull()`, `describe()`, and filtering conditions.
